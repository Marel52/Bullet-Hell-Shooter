# Bullet-Hell-Shooter
Bullet Hell Shooter 2D desarrollado en Unity.

## Descripción
Proyecto de bullet hell shooter donde un ninja verde enfrenta a un boss rana con tres patrones de disparo diferentes. El juego implementa mecánicas de esquive, sistema de doble velocidad y object pooling para optimización.

## Características
- 3 patrones de disparo mecánicamente diferentes
- Duración total: 30 segundos (10 segundos por patrón)
- Sistema de movimiento dual (normal y preciso)
- Object pooling para gestión eficiente de balas
- Contador de balas en tiempo real en UI
- Sistema de colisiones y vida para jugador y boss
- Animaciones dinámicas del boss según patrón activo

## Controles
- WASD / Flechas: Movimiento del jugador
- Shift: Activar movimiento preciso (velocidad reducida)
- Espacio / Z: Disparar
